QUICK START (5 MINUTES)
================================================================================

1. SETUP ENVIRONMENT
   
   Windows:
   -------
   cp .env.example .env
   
   Linux/Mac:
   ----------
   cp .env.example .env

2. EDIT .env WITH YOUR CREDENTIALS
   
   Required:
   - GOOGLE_CLIENT_ID: Get from Google Cloud Console
   - GOOGLE_CLIENT_SECRET: Get from Google Cloud Console  
   - ADMIN_PASSWORD_HASH: Generate with:
     python3 -c "from passlib.context import CryptContext; 
     print(CryptContext(schemes=['bcrypt']).hash('YourPassword123!'))"
   
   Database (pick one):
   - MongoDB Atlas: Set MONGODB_URI to your connection string
   - Local MongoDB: Keep default mongodb://localhost:27017/ecell

3. START SYSTEM

   Using Docker (EASIEST - requires Docker installed):
   --------------------------------------------------
   docker-compose up
   
   Then access:
   - Frontend: http://localhost:3000
   - Backend: http://localhost:8000
   - API Docs: http://localhost:8000/docs
   
   Local Development (requires Python, Node, MongoDB):
   ---------------------------------------------------
   
   Terminal 1 - Backend:
   cd backend
   python -m venv venv
   source venv/bin/activate  (Windows: venv\Scripts\activate)
   pip install -r requirements.txt
   uvicorn app.main:app --reload
   
   Terminal 2 - Frontend:
   cd frontend
   npm install
   npm run dev
   
   Then access:
   - Frontend: http://localhost:5173 or http://localhost:3000
   - Backend: http://localhost:8000
   - API Docs: http://localhost:8000/docs

================================================================================
WHAT EACH COMPONENT DOES
================================================================================

BACKEND (FastAPI + MongoDB)
---------------------------
Location: /backend
Port: 8000
Purpose: REST API for tasks, submissions, authentication

Key Files:
- app/main.py: FastAPI application entry point
- app/routes/auth.py: Login, OAuth, authentication
- app/routes/tasks.py: Task and submission endpoints
- app/database.py: MongoDB connection and indexes
- app/security.py: Password hashing, JWT tokens

FRONTEND (React + Tailwind)
---------------------------
Location: /frontend
Port: 3000 or 5173
Purpose: Web interface for students and admins

Key Files:
- src/main.tsx: React entry point
- src/App.tsx: Router and main layout
- src/pages/: Page components (Login, Dashboard, etc.)
- src/components/: Reusable components (TaskCard, etc.)
- src/api/: API client functions

DATABASE (MongoDB)
------------------
Collections:
- users: Student/faculty accounts
- tasks: Task definitions
- submissions: Student submissions

Indexes automatically created on startup for performance.

NGINX (Production)
------------------
Used only in production (docker-compose.prod.yml)
Provides reverse proxy, SSL/TLS, and rate limiting

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: "Cannot connect to MongoDB"
SOLUTION:
1. Ensure MongoDB is running
2. Check MONGODB_URI in .env
3. If using local: mongod must be running
4. If using Atlas: Check connection string has password

PROBLEM: "Port already in use"
SOLUTION:
1. Backend: Change port in backend/app/main.py
2. Frontend: Change port in frontend/vite.config.ts
3. Or kill the process using the port

PROBLEM: "Google OAuth not working"
SOLUTION:
1. Check GOOGLE_CLIENT_ID in .env
2. Verify redirect URIs in Google Console include localhost:3000
3. Restart frontend after updating .env

PROBLEM: "Admin login not working"
SOLUTION:
1. Check ADMIN_EMAIL in .env (default: admin@ecell.com)
2. Check ADMIN_PASSWORD_HASH is set
3. Verify password matches the hash (or regenerate hash)
4. Restart backend after changing .env

PROBLEM: "Frontend build fails"
SOLUTION:
1. Delete node_modules: rm -rf node_modules
2. Reinstall: npm install
3. Clear cache: npm cache clean --force
4. Try build again: npm run build

PROBLEM: "Backend tests fail"
SOLUTION:
1. Check MongoDB is running
2. Verify Python 3.10+ installed
3. Run: pip install -r requirements.txt
4. Check .env has all required variables

PROBLEM: "Tests pass but system doesn't work"
SOLUTION:
1. Check .env has valid credentials
2. Ensure ports aren't blocked by firewall
3. Check Docker is running (if using docker-compose)
4. View logs: docker-compose logs backend
