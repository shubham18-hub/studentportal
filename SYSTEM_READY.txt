HOW TO RUN
================================================================================

OPTION 1: Docker (Easiest - 2 commands)
---------------------------------------
1. docker-compose up
2. Open http://localhost:3000

OPTION 2: Local Development (Requires setup)
--------------------------------------------
1. Backend:
   cd backend
   python -m venv venv
   venv\Scripts\activate (Windows)
   pip install -r requirements.txt
   uvicorn app.main:app --reload

2. Frontend:
   cd frontend
   npm install
   npm run dev

3. Open http://localhost:3000

See HOW_TO_RUN.txt for detailed instructions
